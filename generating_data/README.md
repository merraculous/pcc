Generating Data
===

This project focuses on visualization of generated data to give practice to creating graphs of information. No Pygal is used.

Files
---

- **die_visual:** Create two dice and roll each number of times. Store summation of each roll. Use results to create histogram of frequency of each possible summation. Show histogram in browswer.
- **die:** Die class used to define a die.
- **rw_visual:** Create scatter plot of a randomized walk from red spot (start) to green (end). Continuously creates plots until user says no.
- **random_walk:** RandomWalk class used to define a randomized scattered plot.
- **scatter_squares:** create a plot graph of squares from 0-1000 and plot on graph. Stored as 'squares_plot.png'.
